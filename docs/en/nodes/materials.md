# Built-in material catalogue

Every new project gets `assets/materials/library/` with **80** materials. This page is generated.

![All materials](/images/materials.png)

Each material is an ordinary node graph: double-click it to change colours, noise scale or roughness. To use one, drag the `.kmat` onto an object or into the `shader` field of the MeshRenderer.
