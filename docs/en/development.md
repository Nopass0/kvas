# Development and contribution

For cloning, prerequisites, build and run commands, complete testing, coverage, performance methodology, docs, and pull request preparation, use the repository's [Development Guide](/DEVELOPMENT) and [Contribution Guide](https://github.com/Nopass0/kvas/blob/main/CONTRIBUTING.md).

The [project map](/PROJECT_MAP) points to the source crates and sample projects. AI agents and human contributors should follow the root [AGENTS.md](https://github.com/Nopass0/kvas/blob/main/AGENTS.md), including the required full test gate before every commit and the extra benchmark evidence required for performance changes.

Feature plans, priority definitions, current limitations, and acceptance expectations are tracked in the [roadmap](/ROADMAP).
