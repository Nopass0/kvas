# Быстрый старт

Kvas - это workspace на Rust: редактор (`kvas_editor`), проигрыватель (`kvas_player`), движок и рендерер.
Нужен [Rust](https://rustup.rs) и видеокарта с Vulkan или DirectX 12. Проверено на Windows.

## Запуск редактора

```bash
cargo run -p kvas_editor                      # менеджер проектов: недавние, открыть, создать 3D / 2D
cargo run -p kvas_editor -- games/demo        # сразу открыть проект
cargo run -p kvas_editor -- games/demo --play # открыть и сразу нажать Play
cargo build -p kvas_player                    # один раз: редактор копирует его в собранную игру
```

Добавьте `--release`, когда нужна скорость. Скрипты редактор собирает тем же профилем, которым собран сам.

## Управление в сцене

| Действие | Ввод |
|---|---|
| Летать камерой | зажать ПКМ, затем W A S D Q E (Shift - быстрее) |
| Панорама / зум / вращение | СКМ / колесо / Alt + ЛКМ |
| Показать выбранное | F (или двойной клик в Иерархии) |
| Двигать / Вращать / Масштабировать | W / E / R (Ctrl при перетаскивании - привязка) |
| Play / Stop | кнопка в панели или Ctrl+P (изменения во время игры отбрасываются) |
| Сохранить, Отменить, Повторить, Дублировать, Удалить | Ctrl+S, Ctrl+Z, Ctrl+Y, Ctrl+D, Del |
| Поставить модель | перетащить из панели Project в сцену |

## Проект

Проект - это папка: `project.json`, `assets/` (сцены, модели, текстуры, шейдеры, материалы) и `scripts/` (крейт `cdylib`).
Первый скрипт: кнопка **+ New script** в панели Project, выберите шаблон, сохраните - редактор сам соберёт библиотеку и перезагрузит скрипты.

## Сборка игры

`File → Build Game` или без окна:

```bash
cargo run -p kvas_editor -- --build games/demo
```

Результат лежит в `<проект>/build/`: `game.exe`, `game.pak` и библиотека скриптов.
