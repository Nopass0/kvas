# Как соединяются ноды

Каждый сокет несёт три числа (vec3). Число хранится во всех трёх каналах, цвет — как RGB, вектор — как XYZ. Поэтому **любой выход подключается к любому входу**, а смысл задают тип и приведение.

## Типы сокетов

| Тип | Значок | Примеры |
|---|---|---|
| число | серый круг | Roughness, Factor, Scale, маски шумов |
| цвет | жёлтый круг | Base color, Colour, Stop 1..4 |
| вектор | фиолетовый ромб | Vector, Coords, UV, Normal |

## Приведение на входе

ПКМ по входу (или список в Инспекторе) выбирает, как входящее значение превращается перед использованием. На связи появляется значок. Цвет, подключённый к числовому входу, по умолчанию берёт «Яркость».

| № | Приведение | Значок |
|---|---|---|
| 0 | Auto | `` |
| 1 | Red / X | `R` |
| 2 | Green / Y | `G` |
| 3 | Blue / Z | `B` |
| 4 | Luminance | `L` |
| 5 | Average | `Avg` |
| 6 | Length | `Len` |
| 7 | Largest | `Max` |
| 8 | Invert (1 - x) | `1-x` |
| 9 | Negate | `-x` |
| 10 | Clamp 0..1 | `0..1` |
| 11 | To 0..1 (x * 0.5 + 0.5) | `½` |
| 12 | To -1..1 (x * 2 - 1) | `±` |

## Несколько выходов

«Картинка» отдаёт цвет, R, G, B и яркость; «Текстура Вороного» — коэффициент, расстояние, край, значение и цвет ячейки; «Координаты текстуры» — UV, объект, мир, нормаль, отражение и экран; «Текстура кирпича» — цвет, маску, значение кирпича и расстояние до шва. Тяните связь от нужного выхода; выход 0 — основной.

## Горячие клавиши

Shift+A или двойной клик — добавить ноду; Ctrl+C / V / D — копировать / вставить / дублировать; Delete или X — удалить; Ctrl+G — рамка-комментарий; Ctrl+L — выделить всё, что питает выделенное; Alt+D — отключить входы; H — превью внутри нод; P — превью выбранной ноды; стрелки — сдвиг; F — весь граф; 1 — масштаб 100%; Ctrl+S — сохранить; Ctrl+E — экспорт в WGSL; K — шпаргалка.

## Пример: мрамор из базовых нод

1. «Координаты текстуры» (World) → «Преобразование координат» (масштаб 3).
2. «Векторная математика» (Скалярное произведение) с вектором (0.82, 0.31, 0.48) — направление прожилок.
3. «Текстура шума» (масштаб 0.9, детализация 7, шероховатость 0.58) — турбулентность.
4. «Математика» (Умножить и сложить): шум × 3 + направление → фаза; «Синус» → «Модуль» — тонкие прожилки около нуля.
5. «Color ramp» (Плавно): цвет прожилки в 0, фон с 0.16.
6. «Смешать цвета» (Перекрытие) с цветным шумом — облачность; «Перевод диапазона» прожилок → Roughness; «Рельеф» из прожилок → Normal.

Готовые графы — `materials/library/Game Ready/`: откройте любой и посмотрите, как он собран.
