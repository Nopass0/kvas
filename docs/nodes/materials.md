# Каталог встроенных материалов

В каждый проект кладётся папка `assets/materials/library/` с **364** материалами. Страница создаётся автоматически.

![Все материалы](/images/materials.png)

Каждый материал - обычный граф нод: откройте двойным кликом и меняйте цвета, масштаб шума, шероховатость. Чтобы применить - перетащите `.kmat` на объект или в поле `shader` компонента MeshRenderer.
