# Шумы

Фрактальные, Перлин, Вороной, трещины, облака, грязь. По умолчанию показывают превью.

Страница создаётся из кода библиотеки. Типы сокетов: **число** (серый круг), **цвет** (жёлтый круг), **вектор** (фиолетовый ромб). Любой выход можно подключить к любому входу; если типы различаются, на входе выбирается приведение (ПКМ по входу). См. [как соединяются ноды](../wiring).

## Noise

Простой гладкий шум (2D, использует X и Z координат).

*Где работает: материал, шейдер объекта, эффект камеры*

**Входы**

| Вход | Тип | Если не подключён |
|---|---|---|
| Coords | вектор | позиция в мире |

**Параметры** (меняются прямо в ноде или в Инспекторе)

| Параметр | По умолчанию | Диапазон | Варианты |
|---|---|---|---|
| scale | 2 | 0.01..100 | - |

**Выходы**

| Выход | Тип |
|---|---|
| Factor | число |
| Inverted | число |
| Sharp | число |

> Работает как маска: в **Factor** «Смешать цвета», в **Position** Color ramp, в **Roughness / Metallic / Alpha / Height** выхода или во вход **A/B** «Математики».

Пример: «Координаты текстуры» (World) → «Преобразование координат» (масштаб 4) → **Noise** (вход Coords) → «Color ramp» → Output > Base color.
