# Векторы

Компоненты, скалярное и векторное произведение, повороты, координаты.

Страница создаётся из кода библиотеки. Типы сокетов: **число** (серый круг), **цвет** (жёлтый круг), **вектор** (фиолетовый ромб). Любой выход можно подключить к любому входу; если типы различаются, на входе выбирается приведение (ПКМ по входу). См. [как соединяются ноды](../wiring).

## Red

Копирует красный канал во все каналы.

*Где работает: материал, шейдер объекта, эффект камеры*

**Входы**

| Вход | Тип | Если не подключён |
|---|---|---|
| Vector | вектор | `0.0` |

**Выход**: вектор

> Подключается к входам **Vector / Coords / UV** текстур и шумов (координаты) или к **Normal** выхода. Для одного канала выберите приведение «X/Y/Z».

Пример: «Координаты текстуры» (World) → «Преобразование координат» (масштаб 4) → **Red** (вход Vector) → «Color ramp» → Output > Base color.

## Jitter coords

Добавляет к координатам плавный шум, чтобы убрать заметные повторы.

*Где работает: материал, шейдер объекта, эффект камеры*

**Входы**

| Вход | Тип | Если не подключён |
|---|---|---|
| Vector | вектор | позиция в мире |
| Amount | число | `0.2` |

**Параметры** (меняются прямо в ноде или в Инспекторе)

| Параметр | По умолчанию | Диапазон | Варианты |
|---|---|---|---|
| scale | 4 | 0.01..100 | - |

**Выходы**

| Выход | Тип |
|---|---|
| Vector | вектор |
| X | число |
| Y | число |
| Z | число |

> Подключается к входам **Vector / Coords / UV** текстур и шумов (координаты) или к **Normal** выхода. Для одного канала выберите приведение «X/Y/Z».

Пример: «Координаты текстуры» (World) → «Преобразование координат» (масштаб 4) → **Jitter coords** (вход Vector) → «Color ramp» → Output > Base color.
