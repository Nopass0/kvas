# Ввод

Константы, текстуры, время, UV.

Страница создаётся из кода библиотеки. Типы сокетов: **число** (серый круг), **цвет** (жёлтый круг), **вектор** (фиолетовый ромб). Любой выход можно подключить к любому входу; если типы различаются, на входе выбирается приведение (ПКМ по входу). См. [как соединяются ноды](../wiring).

## Color

A constant colour.

*Где работает: материал, шейдер объекта, эффект камеры*

**Параметры** (меняются прямо в ноде или в Инспекторе)

| Параметр | По умолчанию | Диапазон | Варианты |
|---|---|---|---|
| цвет | 0.80, 0.80, 0.80 | 0..1 | - |

**Выходы**

| Выход | Тип |
|---|---|
| Colour | цвет |
| R | число |
| G | число |
| B | число |
| Luma | число |

> Обычно идёт в **Output > Base color** или **Emission**, либо во вход **A/B** ноды «Смешать цвета». В числовой вход приводится к яркости.

## Value

A constant number.

*Где работает: материал, шейдер объекта, эффект камеры*

**Параметры** (меняются прямо в ноде или в Инспекторе)

| Параметр | По умолчанию | Диапазон | Варианты |
|---|---|---|---|
| value | 0.5 | -100..100 | - |

**Выход**: число

> Работает как маска: в **Factor** «Смешать цвета», в **Position** Color ramp, в **Roughness / Metallic / Alpha / Height** выхода или во вход **A/B** «Математики».

## Texture

Samples one of the material images (slot 0 albedo, 1 normal, 2 ORM).

*Где работает: материал, шейдер объекта*

**Входы**

| Вход | Тип | Если не подключён |
|---|---|---|
| UV | вектор | UV объекта |

**Параметры** (меняются прямо в ноде или в Инспекторе)

| Параметр | По умолчанию | Диапазон | Варианты |
|---|---|---|---|
| slot | 0 | 0..2 | 0 Slot 0 (albedo), 1 Slot 1 (normal), 2 Slot 2 (ORM) |
| tiling | 1 | 0.01..100 | - |

**Выходы**

| Выход | Тип |
|---|---|
| Colour | цвет |
| R | число |
| G | число |
| B | число |
| Luma | число |

> Обычно идёт в **Output > Base color** или **Emission**, либо во вход **A/B** ноды «Смешать цвета». В числовой вход приводится к яркости.

Пример: «Координаты текстуры» (World) → «Преобразование координат» (масштаб 4) → **Texture** (вход UV) → «Color ramp» → Output > Base color.

**Выходы**

| Выход | Тип |
|---|---|

| Sine | число |
| Fraction | число |

> Работает как маска: в **Factor** «Смешать цвета», в **Position** Color ramp, в **Roughness / Metallic / Alpha / Height** выхода или во вход **A/B** «Математики».

**Выход**: цвет

> Обычно идёт в **Output > Base color** или **Emission**, либо во вход **A/B** ноды «Смешать цвета». В числовой вход приводится к яркости.

## Triplanar texture

Проецирует картинку материала по трём осям мира, без растяжения на склонах.

*Где работает: материал, шейдер объекта*

**Параметры** (меняются прямо в ноде или в Инспекторе)

| Параметр | По умолчанию | Диапазон | Варианты |
|---|---|---|---|
| slot | 0 | 0..2 | 0 Slot 0 (albedo), 1 Slot 1 (normal), 2 Slot 2 (ORM) |
| scale | 1 | 0.01..50 | - |
| sharpness | 4 | 1..32 | - |

**Выходы**

| Выход | Тип |
|---|---|
| Colour | цвет |
| R | число |
| G | число |
| B | число |
| Luma | число |

> Обычно идёт в **Output > Base color** или **Emission**, либо во вход **A/B** ноды «Смешать цвета». В числовой вход приводится к яркости.

## Image texture

Картинка из проекта. Выберите файл прямо в ноде; до трёх картинок на материал (слоты 0..2). Выходы: цвет, каналы и яркость.

*Где работает: материал, шейдер объекта*

**Входы**

| Вход | Тип | Если не подключён |
|---|---|---|
| Vector | вектор | UV объекта |

**Параметры** (меняются прямо в ноде или в Инспекторе)

| Параметр | По умолчанию | Диапазон | Варианты |
|---|---|---|---|
| slot | 0 | 0..2 | 0 Slot 0 (albedo), 1 Slot 1 (normal), 2 Slot 2 (ORM) |
| tiling x | 1 | 0.01..100 | - |
| tiling y | 1 | 0.01..100 | - |
| offset x | 0 | -10..10 | - |
| offset y | 0 | -10..10 | - |
| rotation | 0 | -1..1 | - |

**Выходы**

| Выход | Тип |
|---|---|
| Colour | цвет |
| R | число |
| G | число |
| B | число |
| Luma | число |

> Обычно идёт в **Output > Base color** или **Emission**, либо во вход **A/B** ноды «Смешать цвета». В числовой вход приводится к яркости.

Пример: «Координаты текстуры» (World) → «Преобразование координат» (масштаб 4) → **Image texture** (вход Vector) → «Color ramp» → Output > Base color.

## RGB

Цвет с выходами R, G, B и яркости.

*Где работает: материал, шейдер объекта, эффект камеры*

**Входы**

| Вход | Тип | Если не подключён |
|---|---|---|
| Colour | цвет | `0.8, 0.5, 0.2` |

**Выходы**

| Выход | Тип |
|---|---|
| Colour | цвет |
| R | число |
| G | число |
| B | число |
| Luma | число |

> Обычно идёт в **Output > Base color** или **Emission**, либо во вход **A/B** ноды «Смешать цвета». В числовой вход приводится к яркости.

Пример: «Картинка» (Цвет) → **RGB** (вход Colour) → Output > Base color.
